App Android — Kotlin + Jetpack Compose
MainActivity MainActivity.kt

Entry point. Calls AppContainer.init().

Service locator + shared state core/AppContainer.kt

Picks Mock vs API mode; OutingSession shares the itinerary between screens.

Navigation (3 screens) navigation/PlaceExplorerNavHost.kt

Home → Itinerary → Place Details (place id URL-encoded in the route).

Home screen presentation/home/HomeScreen.kt + HomeViewModel.kt

GPS fix, destination search, duration / time-of-day / interests / food questionnaire.

Itinerary & Details screens presentation/itinerary/… · presentation/details/…

Shows the plan; tapping a stop loads its details.

Networking stack data/remote/ ApiClient · PlanApiService · ApiOutingRepository · ApiDtos

Retrofit + OkHttp + kotlinx-serialization. 4-min read timeout (slow Overpass).

Device location location/DeviceLocationProvider.kt · search/LocationSearcher.kt

Fused GPS provider; destination search interface (API or mock).

⇄ HTTP / JSON
API Backend — Python FastAPI

Runs POST /api/plan: RAG → geocode → MCP search → rank → OSRM routing → schedule.

→ stdio
AI AI layer — Gemini · RAG · MCP
Gemini agent loop agent/mcp_agent.py

Function-calling loop (max 5 turns) powering POST /api/agent/chat.

MCP server (subprocess, stdio) mcp_server/server.py

Exposes 4 tools: search_places · get_place_details · get_route · get_route_matrix. Same server used by the agent and the plan pipeline.

RAG pipeline rag/ rag_pipeline · document_loader · text_splitter · embedding_service · vector_store

Embeds destination guides (Gemini embeddings), cosine-similarity search over a local store.

Knowledge base knowledge_base/destinations/*.md

Pune & Goa travel guides — the RAG source documents.

Skills & intent routing skills/ intent_router · skill_selector · skill_loader · restaurant_discovery/SKILL.md

Keyword-based routing picks skills and decides RAG vs MCP for each message.

External External services (called by the backend)

Google Gemini API main.py client · rag/embedding_service.py

LLM answers, itinerary titles, embeddings. Key from .env (GEMINI_API_KEY).

🗺️

Geocode / reverse geocode. Debounced on the app side per usage policy.

Complete flow — “Generate my outing”

1
Home screen opens

GPS fix → GET /api/geocode/reverse labels the device coordinates as the default destination city.

HomeViewModel.kt → geocode_tools.py
2
Destination search

Debounced text search → GET /api/geocode returns candidate places to pick from.

ApiLocationSearcher.kt → geocode_tools.py
3
Questionnaire → Plan request

Duration, time of day, interest, food preference → Retrofit POST /api/plan with an OutingRequest.

HomeViewModel.kt → ApiOutingRepository.kt
4
RAG retrieval

Query embedded and matched against destination guides; context attached to the pipeline.

itinerary_generator.py → rag_pipeline.py → knowledge_base/
5
MCP place discovery

FastAPI spawns the MCP server (stdio) and calls search_places per category — real places from Overpass.

itinerary_generator.py → mcp_server/server.py → place_tools.py
6
Validate & rank

Drops places without coordinates (never fabricates), ranks by distance + fame, keeps top 20.

itinerary_generator.py
7
Route & schedule

One OSRM Table request → road-time matrix → nearest-neighbour ordering → timed stops within the outing window; Gemini writes only the title.

route_tools.py · itinerary_generator.py
8
Itinerary screen

Structured Itinerary JSON → stored in OutingSession → stops, travel legs, “worth a detour”, food picks.

ItineraryScreen.kt
9
Place details

Tap a stop → GET /api/places/{id} resolves the exact OSM id + nearby restaurants/attractions.

PlaceDetailsViewModel.kt → place_details_service.py
+
Free chat (secondary)

POST /api/agent/chat: intent router picks RAG / MCP, skills add instructions, Gemini function-calls MCP tools in a loop.

mcp_agent.py · skills/ · rag_pipeline.py
Error philosophy: the backend never fabricates data — unresolvable destination → 400, no usable places → 503, routing unavailable → 503 — and the app never silently falls back from API to mock mode.
